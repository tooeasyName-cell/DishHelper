# DishHelper

在电脑上使用的饮食生活 AI 助手，支持规划、买菜、备菜与烹饪讨论，可保留会话背景和操作步骤。

## 下载与启动

1. 在 [Releases](https://github.com/tooeasyName-cell/DishHelper/releases) 下载 `DishHelper-版本号-Windows-x64.zip`。GitHub 自动提供的 **Source code** 是源码，不是免安装包。
2. 完整解压 ZIP，双击文件夹中的 **DishHelper.exe**。无需安装 Python；请保留同目录的 `_internal` 文件夹。
3. 程序会打开本机浏览器。若没有自动打开，复制启动窗口显示的 `http://127.0.0.1:端口` 地址到浏览器。

适用于 Windows 10/11 64 位。本地演示不需要联网；真实 AI 回答需要网络和你自己的模型服务账号。关闭启动窗口或按 Ctrl+C 停止程序。

## 配置模型

首次启动预置本地演示和 DeepSeek 模型档案，并将各场景默认模型设为 DeepSeek。真实 AI 需自行配置对应服务的 API Key；选择“本地演示”可不联网熟悉界面，演示只返回固定样例，不理解输入。已有用户的模型档案和默认选择不会被更新覆盖。

展开侧栏“模型初始设置”，可使用预置的 DeepSeek 档案，或新建 `openai_chat` 档案并填写服务商提供的 Base URL 和模型名称。预置 DeepSeek 档案的凭据引用为 `DEEPSEEK_API_KEY`，在密码框输入自己的 API Key 后保存。两个 DeepSeek 档案的近期问答轮数分别为 4 和 0；三个场景默认选择 0 轮档案。

密码框输入的 Key 仅在当前程序运行期间有效。如需重启后继续使用，可在下述数据目录中创建 `.env`，写入 `DEEPSEEK_API_KEY=你的密钥`，然后重启；也可自行设置同名系统环境变量。使用其他模型时，请对应其凭据引用填写环境变量名。请妥善保管该文件，不要随截图、日志或压缩包分享。

支持兼容 OpenAI Chat Completions 的服务，不支持所有服务商的原生协议。调用费用由你的模型服务商收取。程序会发送本轮输入和所需的会话背景，输入前请考虑所选服务商的数据处理规则。

## 日常使用

- 选择日期和场景，输入需求并发送；同一天的不同场景可接收相关共享信息。
- “当前任务背景”保留仍需查阅的步骤或条件；“持续参考”可跳转到详细回复。部分回复会额外调用模型进行阅读排版。
- “共享信息”可查看、编辑或删除记忆；“历史会话”可恢复、导出或删除讨论。
- “近期成功问答轮数 N”可设为 0–20；0 表示不附带近期问答原文，仍会使用工作记忆。
- “状态与请求检查”和版本比较可用于检查模型输入输出。额外比较、排版或整理可能产生模型费用。
- 本版本未提供联网搜索及平台登录功能。

模型可能出错，请核对影响食品安全的建议。

## 测试提示词

在成功回复下展开“反馈与版本比较”，可选择“场景说明·详细版”比较较长场景说明，或选“自主编辑请求 JSON”，修改 messages 中 role 为 system 的 content 后预览和测试。比较额外调用一次模型，不会自动成为默认提示词，也不会修改原会话记忆。免安装版的默认提示词随程序构建，不能通过编辑旁边的源码文件永久替换。

## 数据、备份与升级

免安装版的数据保存在 `%LOCALAPPDATA%\DishHelper`，可将此路径粘贴到文件资源管理器地址栏打开。会话和模型配置保存在其中的 `dishhelper.sqlite3`。

备份时先停止程序，再复制整个数据目录。升级时停止旧程序，将新版本解压到新文件夹并启动；程序会继续使用同一数据目录。不要把仍在运行的数据文件覆盖回去。

“清空使用数据”需要确认，保留模型档案与应用设置；不会删除 `.env` 或已经导出的文件。卸载时删除程序文件夹即可；需要彻底移除记录时，再自行删除上述数据目录。

## 常见问题

- 页面打不开：检查启动窗口中的错误和实际端口。端口占用时程序会尝试其他本机端口。
- 模型调用失败：检查网络、Key、余额、模型名称和服务地址；按页面提示修正后重试。
- 不要只复制 EXE：运行所需文件在 `_internal` 中，必须保留完整文件夹。

## 从源码启动

源码使用者需自行准备兼容的 Python 环境（当前发布构建使用 Python 3.12 x64）。Windows 可双击 `start.cmd`，首次会安装依赖；也可自行创建虚拟环境，安装 `requirements.txt` 后运行 `python -m streamlit run app.py --server.address 127.0.0.1`。源码版默认在项目的 `data` 文件夹保存记录。
